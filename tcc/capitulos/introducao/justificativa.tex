\section*{\large 1.3 JUSTIFICATIVA}
\thispagestyle{empty}

    A transformação digital vem trazendo mudanças para o setor jurídico, principalmente com o uso de sistemas 
para auxiliar na organização e no gerenciamento das atividades. Os escritórios de advocacia trabalham diariamente 
com uma grande quantidade de informações, documentos, processos e prazos, tornando necessário ter uma forma mais
organizada de realizar esse controle.
    Nesse contexto, este trabalho se justifica pela necessidade de desenvolver uma plataforma web para gestão de
escritórios de advocacia, com o objetivo de centralizar informações e facilitar o gerenciamento das atividades 
realizadas no escritório. A utilização da plataforma pode contribuir para uma melhor organização dos dados, 
facilitar o acesso às informações e reduzir a dependência de processos realizados manualmente.
    Dessa forma, o desenvolvimento da plataforma busca aplicar os conhecimentos da Engenharia de Software na 
criação de uma solução voltada para uma necessidade presente na rotina dos escritórios de advocacia, utilizando 
a tecnologia como forma de auxiliar na organização e gestão das atividades.
